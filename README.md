# 🏦 Sistema Bancário em C

Projeto desenvolvido para a disciplina de **Algoritmos e Pensamento Computacional** do curso de Engenharia de Software.

## 📋 Descrição

Este sistema simula um caixa eletrônico simples, permitindo que o usuário realize operações bancárias básicas por meio de um menu interativo no terminal.

## 🚀 Funcionalidades

- Consultar saldo
- Realizar depósito
- Realizar saque
- Validação de valores informados
- Impedir saque superior ao saldo disponível
- Tratamento de opções inválidas
- Encerramento seguro do sistema

## 💻 Tecnologias Utilizadas

- Linguagem C
- GCC (GNU Compiler Collection)
- Git
- GitHub

## ▶️ Como Executar

### Compilar

```bash
gcc caixaeletronico.c -o caixaeletronico
```

### Executar

No Windows:

```bash
caixaeletronico.exe
```

No Linux:

```bash
./caixaeletronico
```
